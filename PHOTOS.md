# Photos for the website

The site has **28 photos**, shown in 32 places. Each one has a file name. Upload a photo with that exact name to
`assets/photos/` and it appears on the site, in every place that uses it. No code changes are needed.

Until a photo exists, its slot is hidden and the page reads as text only, so visitors never see an empty box.

## See where each photo goes

Open any page with `?photos` at the end of the address, for example
`https://sheedosa.github.io/alkhawarizmi-ai-academy/?photos`. Every empty slot then shows its number, file name,
what to photograph and the size. Filled slots show a small tag with their file name. The setting stays on while
you browse; add `?photos=0` to turn it off. Visitors never see these labels.

## How to upload

1. On GitHub, open the repository and go to the `assets/photos` folder.
2. Click **Add file → Upload files**, drag the photos in, and click **Commit changes**.
3. Wait about two minutes, then refresh the site.

**File rules:** JPG, named exactly as below (lower case, `.jpg`). Long edge at least the size shown, under
about 600 KB each (export at quality 75–80). Landscape photos should be landscape; crop to roughly the ratio shown.
Photos are cropped to fill their frame, so keep the subject away from the edges.

**What works best:** real people working in the academy's rooms, hands on keyboards, screens showing real work,
printed materials. Avoid stock photos of people pointing at laptops. Get permission from anyone recognisable.
